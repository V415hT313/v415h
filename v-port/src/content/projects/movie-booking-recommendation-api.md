Go, PostgreSQL, Redis, Docker, Anthropic API

- Built a Go REST API for cinema bookings (users, movies, projections, tickets, reservations) with PostgreSQL, Redis caching, and role based auth.
- Designed a hybrid recommendation engine combining rule based scoring with LLM re-ranking via the Anthropic API, with automatic fallback on failure.
