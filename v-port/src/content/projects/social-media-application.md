React, TypeScript, Radix UI

- Built a social media web app using React, TypeScript, and Vite, with React Router for navigation and TanStack Query for data fetching/caching.
- Used Appwrite as backend-as-a-service for auth, database, and file storage, with React Hook Form + Zod for validated post and profile forms.
- Built the UI with Radix UI components and Tailwind CSS, including infinite-scroll feeds via React Intersection Observer.
