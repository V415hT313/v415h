Next.js, TypeScript, Fabric.js

- Built a real-time collaborative design tool for canvas based shape rendering and manipulation.
- Implemented live multi user collaboration with Liveblocks real time cursor tracking, shared canvas state, and in-app comments across concurrent sessions.
- Built the UI with Radix UI and Tailwind CSS, and added canvas-to-PDF export functionality using jsPDF.
